# 90 Day Plan (1 Oct – 30 Dec 2026)

Targets: **10 components a month, 30 in total** (Track A) and **one agent log a week, 4+ a month, each a different kind of task** (Track B).

Weeks run Thursday to Wednesday, starting 1 October. October fell two short (8), so December carries 12 to keep the total at 30.

## Track B: agent log (one per week, each a different kind of task)

| Week | Task | Kind |
|---|---|---|
| 01 | Scaffold, build and deploy this gallery plus the first two components | Code generation + deploy |
| 02 | Research and curate a website-section moodboard in Figma | Research & curation |
| 03 | Study 10 component libraries in the browser and turn them into a 14-component plan | Competitive research & planning |
| 04 | Split the registry into per-week files so several agents can add components at once | Refactoring |
| 05 | Build 14 components with 7 sub-agents working in parallel | Multi-agent orchestration |
| 06 | Run the cross-browser suite on the new components and fix what fails | Debugging |
| 07 | Accessibility audit (axe + keyboard) of the new components | Accessibility audit |
| 08 | Script that writes the weekly Discord posts from the registry and checks the 2,000-character limit | Workflow automation |
| 09 | Visual QA of the live site in a real Chrome browser, light and dark, desktop and mobile | Visual QA |
| 10 | SEO and metadata audit of the site, and fixes | SEO audit |
| 11 | Translate UI copy and check layout in a second language | Localisation |
| 12 | Batch-optimise and rename image assets | File automation |
| 13 | 90-day retrospective from the logs | Analysis |

If a week has nothing an agent can do, the log records the task that could not be automated, why, and what was tried.
